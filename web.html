Thème 2 • Le Web

Comment fonctionne une page Web ?

Le Web repose sur des pages reliées par des hyperliens, identifiées par des URL et échangées entre clients et serveurs grâce au protocole HTTP ou HTTPS.

Cours

1. Internet et Web : deux notions différentes

Internet est l'infrastructure réseau mondiale. Le Web est un service qui fonctionne au-dessus d'Internet et permet notamment de consulter des pages reliées entre elles.

Exemple : un navigateur utilise Internet pour demander une page à un serveur distant.

Repères : Ted Nelson présente le concept d’hypertexte en 1965. En 1989, Tim Berners-Lee propose au CERN le système qui deviendra le Web. En 1993, le CERN place le logiciel du Web dans le domaine public et le navigateur Mosaic se diffuse. À partir de 1995, JavaScript et PHP illustrent le développement de pages interactives et dynamiques.

Cours

2. Hypertexte et hyperliens

Une page Web peut contenir des hyperliens. Ils permettent de passer d'une ressource à une autre : page, image, vidéo, document ou autre site.

HTML <a href="cours.html">Voir le cours</a>

La balise <a> permet de créer un lien hypertexte.

Cours

Une URL (Uniform Resource Locator) indique l'emplacement d'une ressource sur le Web.

HTTPS signifie que les échanges HTTP sont protégés par TLS. Cela ne prouve pas à lui seul qu'un site est honnête ou fiable.

Cours

4. HTML : le contenu et la structure

Le langage HTML décrit la structure et le contenu d'une page : titres, paragraphes, images, liens, listes, tableaux, etc.

Le navigateur interprète le document HTML pour construire l'affichage de la page.

<h1>Mon titre</h1>
<p>Mon premier paragraphe.</p>
<a href="page2.html">Suite</a>

Cours

5. CSS : la présentation

Le langage CSS sert principalement à définir la présentation : taille des textes, espacements, disposition, couleurs et apparence générale.

Idée essentielle : HTML = contenu/structure ; CSS = présentation.
h1 {
  font-size: 2rem;
}

p {
  line-height: 1.6;
}

6. Client, serveur et HTTP

Le navigateur joue généralement le rôle de client. Il envoie une requête au serveur, qui renvoie une réponse contenant par exemple un document HTML.

Navigateurclient
→
Requête HTTPGET /index.html
→
Serveur Webtraite la demande
Navigateuraffiche la ressource
←
Réponse HTTPstatut + contenu
←
Serveur Webrenvoie la réponse
GET /lycee-general-et-technologique/?classe=2de&rubrique=formations HTTP/1.1
Host: marie-rivier.com

HTTP/1.1 200 OK
Content-Type: text/html; charset=utf-8

GET est la méthode, /lycee-general-et-technologique/ le chemin et classe et rubrique les paramètres. Le fragment de l’URL reste dans le navigateur. Le statut 200 indique un succès. Un statut 404 indique que la ressource demandée est introuvable.

Le serveur peut renvoyer un fichier existant ou produire une page selon les paramètres. Un script JavaScript déjà chargé peut aussi réagir à un clic directement dans le navigateur.

Cours

7. Les moteurs de recherche

Un moteur de recherche explore et indexe de nombreuses pages, puis classe les résultats en fonction de différents critères. L'ordre obtenu n'est donc pas une preuve de vérité.

1Exploration

Des robots parcourent des pages accessibles.

2Indexation

Les informations utiles sont organisées dans un index.

3Classement

Les résultats sont ordonnés selon la requête et divers critères.

Toujours vérifier l'auteur, la date, la source et recouper une information importante avec d'autres sources fiables.

Cours

8. Navigateur, données et confidentialité

Le navigateur propose des paramètres concernant notamment les cookies, les autorisations accordées aux sites, l'historique, les téléchargements et certaines protections de confidentialité.

Un cookie est une petite donnée qu'un site peut demander au navigateur de conserver. Certains sont utiles au fonctionnement d'un service ; d'autres peuvent participer à la mesure d'audience ou au suivi publicitaire.

Tu peux refuser les traceurs facultatifs, gérer les données enregistrées pour un site et contrôler l’accès à la caméra, au micro ou à la localisation. Une fenêtre privée limite certaines traces sur ton appareil. Le site et le réseau peuvent toujours observer les échanges.

Cours

9. Publication, droit d'auteur et licences

Une ressource trouvée sur le Web n'est pas automatiquement libre de réutilisation. Avant de publier une image, un texte ou un autre contenu, il faut vérifier les droits et la licence associés.

Réflexe : citer la source ne suffit pas toujours à obtenir le droit de réutiliser une œuvre.

Q1 · Repérer les défauts

L’accueil s’affiche avec le style par défaut du navigateur et la manette manque. Dans index.html, href="style.css" et src="manette.svg" demandent deux fichiers dans le même dossier que la page. Ces fichiers se trouvent dans des sous-dossiers.

Q2 · Rétablir la feuille de style et l’image

  • href="Feuille_de_Style/style.css" charge la feuille de style. Le fond devient bleu pâle.
  • src="Images/manette.svg" charge la manette. Garde son texte alternatif alt="Manette de jeu illustrée".

Recopie les noms et la casse des dossiers tels qu’ils figurent dans l’arborescence.

Q3 · Rendre le menu et le lien Conseils cliquables

  • href="top10.html" ouvre la page Top 10 dans le même dossier.
  • href="tutos.html" ouvre la page Tutos dans le même dossier.
  • href="#conseils" vise le titre qui porte id="conseils" dans la page affichée.

Place le texte de chaque lien dans une balise <a>. Les deux pages du menu contiennent un lien de retour vers index.html.

Q4 · Ajouter un lien absolu

L’adresse de la page du CERN sur la naissance du Web contient le schéma https, l’hôte home.cern et le chemin /fr/science/computing/birth-web/. Le navigateur dispose ainsi de l’adresse complète de la ressource.

Q5 · Mettre le titre en vert

Dans Feuille_de_Style/style.css, la règle h1 { color: #176b45; } applique la couleur verte. Le texte « Les jeux de Tom » est écrit dans la balise <h1> du fichier HTML.

Q6 · Lire l’URL du relevé HTTP

http://127.0.0.1:8000/recherche?jeu=tetris&niveau=2#resultat
  • Le schéma est http, l’hôte 127.0.0.1 désigne le poste utilisé et le port est 8000.
  • Le chemin est /recherche. Les deux paramètres sont jeu=tetris et niveau=2.
  • Le navigateur utilise le fragment resultat pour atteindre le titre portant id="resultat".

Q7 · Lire la requête et la réponse

Le navigateur envoie une requête GET vers /recherche?jeu=tetris&niveau=2. Il garde #resultat pour se déplacer dans la page. Le statut 200 OK indique que la demande a réussi et Content-Type: text/html; charset=utf-8 annonce un document HTML encodé en UTF-8.

HTTPS chiffre les échanges, protège leur intégrité et permet au navigateur de vérifier l’identité du serveur pour le nom demandé. Avant de saisir un mot de passe, vérifie le nom de domaine du service.

Q8 · Distinguer le rôle du navigateur et celui du serveur

Le bouton d’astuce exécute du JavaScript dans le navigateur. La ligne message.hidden = !message.hidden affiche ou masque un paragraphe déjà chargé. Une fois la page chargée, l’onglet Réseau ne montre aucune nouvelle requête liée à ce clic.

Dans le relevé du TP, le serveur Python construit le titre à partir de la valeur du paramètre jeu. On lit déjà « Résultat pour tetris » ou « Résultat pour pacman » dans le HTML de la réponse. L’inspecteur montre le DOM, la structure de la page construite par le navigateur, où tu peux retrouver la balise <h1 id="resultat">.

Les liens de recherche de la démonstration en ligne ouvrent deux pages HTML préparées. Pour observer le titre généré par le serveur Python à partir des paramètres, utilise le relevé de la fiche du TP ou la démonstration locale.
