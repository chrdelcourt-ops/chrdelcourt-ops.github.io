Mesurer → décider → convertir / stocker

L'objectif est d'utiliser l'algorithmique pour gérer une chaîne d'énergie : mesurer les grandeurs utiles, prendre une décision automatique puis vérifier que la performance énergétique reste compatible avec le service rendu.

Débogage

Corriger le chauffage

Code à corriger2 erreurs
temperature = 18
consigne = 19

if temperature > consigne:
    print("Chauffage ON")
else
    print("Chauffage OFF")

Erreur 1 : l'exigence demande ON lorsque temperature < consigne.

Erreur 2 : il manque : après else.

if temperature < consigne:
    print("Chauffage ON")
else:
    print("Chauffage OFF")
