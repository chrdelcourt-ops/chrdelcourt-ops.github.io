Repérer puis corriger les erreurs

Code à corriger2 erreurs
temperature = 31
seuil = 28

if temperature < seuil:
    print("Ventilation ON")
else
    print("Ventilation OFF")

Erreur 1 : l'exigence demande ON pour temperature >= seuil.

Erreur 2 : il manque : après else.
