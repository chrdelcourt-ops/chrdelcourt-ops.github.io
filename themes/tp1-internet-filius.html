Étape 2

Tester deux sous-réseaux différents

2
  1. Conserver le LAN A en 192.168.1.0/24.
  2. Créer un LAN B : T1 = 192.168.2.10/24 et T2 = 192.168.2.11/24.
  3. Relier provisoirement les deux switches.
  4. Depuis P1, lancer ping 192.168.2.10.

Q4. Le ping de P1 vers T1 fonctionne-t-il ? Justifier avec les adresses IP et le masque.

Q5. Quel équipement faut-il ajouter pour permettre la communication entre les deux sous-réseaux ?

CAPTURE N°2Ping en échec de P1 vers T1.
Point important : deux réseaux différents ont besoin d'un routeur et de passerelles correctement configurées pour communiquer.

Étape 3

Mettre en place le routage et les passerelles

3
  1. Supprimer le câble direct entre les switches.
  2. Placer un routeur R1 entre SW-A et SW-B.
  3. Interface LAN A : 192.168.1.254/24.
  4. Interface LAN B : 192.168.2.254/24.
  5. Passerelle P1/P2/P3 : 192.168.1.254.
  6. Passerelle T1/T2 : 192.168.2.254.
  7. Tester à nouveau ping 192.168.2.10.

CAPTURE N°3Ping réussi après configuration des passerelles.
À retenir : le routeur relie des réseaux IP différents. La passerelle indique vers quel routeur envoyer un paquet qui sort du réseau local.

Étape 4

Ajouter un serveur DNS

4
  1. Ajouter Serveur_DNS : 192.168.2.20/24, passerelle 192.168.2.254.
  2. Installer puis démarrer l'application Serveur DNS.
  3. Ajouter : www.snt-lab.fr → 192.168.2.30.
  4. Configurer 192.168.2.20 comme DNS sur les postes.
  5. Depuis P1, utiliser nslookup www.snt-lab.fr ou host.

Synthèse

Ce que je dois retenir

NotionDéfinition essentielle
LANRéseau local reliant des équipements proches.
Adresse IPIdentifie une interface sur un réseau IP.
Masque /24Permet de déterminer quelle partie de l'adresse correspond au réseau.
SwitchRelie les équipements d'un même LAN et commute les trames.
RouteurRelie plusieurs réseaux IP et transmet les paquets.
PasserelleAdresse du routeur utilisée pour sortir du sous-réseau local.
DNSTraduit un nom symbolique en adresse IP.
IP / TCPIP adresse et route ; TCP fiabilise le transport.
HTTPProtocole utilisé entre navigateur et serveur Web.

Méthode de diagnostic : Poste → LAN → Passerelle → Routage → DNS → Web
