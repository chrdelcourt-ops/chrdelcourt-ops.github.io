Thème 1 • Internet

Comment les informations circulent-elles sur Internet ?

Internet relie des milliards d'équipements. Pour communiquer, ils utilisent des adresses, découpent les données en paquets et s'appuient sur des protocoles communs.

Cours

1. Internet n'est pas le Web

Internet est une infrastructure mondiale qui relie entre eux de nombreux réseaux informatiques. Le Web est l'un des services qui utilise Internet, au même titre que le courrier électronique ou d'autres services en réseau.

À ne pas confondre : ouvrir une page Web nécessite Internet, mais Internet ne se limite pas au Web.

Cours

2. Identifier les machines : les adresses IP

Pour que des données arrivent au bon destinataire, les équipements utilisent des adresses IP. Une adresse IPv4 est généralement écrite sous la forme de quatre nombres séparés par des points, par exemple 192.168.1.20.

Il existe également IPv6, conçu notamment pour disposer d'un espace d'adressage beaucoup plus vaste.

3. DNS : utiliser des noms plutôt que des nombres

Les humains retiennent plus facilement un nom comme education.gouv.fr qu'une adresse IP. Le système DNS (Domain Name System) permet d'effectuer la correspondance entre un nom de domaine et une adresse IP.

4. Les données sont découpées en paquets

Lorsqu'une information est transmise, elle n'est pas nécessairement envoyée en un seul bloc. Elle est découpée en paquets. Les paquets peuvent emprunter des chemins différents avant d'atteindre leur destination.

5. Le routage : choisir un chemin

Les routeurs font transiter les paquets d'un réseau vers un autre. Chaque routeur prend une décision à partir des informations dont il dispose afin d'orienter le paquet vers sa destination.

Le chemin emprunté peut changer selon l'état du réseau. Internet ne garantit donc pas qu'un paquet utilise toujours le même trajet ni qu'il arrive dans un délai précis.

6. IP et TCP n'ont pas le même rôle

IP

Acheminer

IP s'occupe principalement de l'adressage et de l'acheminement des paquets vers leur destination.

TCP

Fiabiliser

TCP permet notamment de détecter des pertes, d'organiser les données et de demander la retransmission d'informations manquantes lorsque la communication utilise ce protocole.

Important : une transmission peut être fiable sans garantir un temps d'arrivée précis.

Cours

7. Les réseaux pair-à-pair (P2P)

Dans un réseau pair-à-pair, les machines participantes peuvent échanger directement des données et jouer à la fois un rôle de client et de fournisseur de ressources.

Cette architecture possède des usages légitimes. Comme d'autres technologies, elle peut aussi être utilisée pour partager illégalement des œuvres protégées : c'est l'usage qui peut être illicite, pas le principe technique lui-même.

Cours

8. Internet fonctionne sur des réseaux physiques variés

Internet n'impose pas un seul support matériel. Les données peuvent circuler sur différents réseaux : fibre optique, câbles en cuivre, réseaux mobiles, Wi-Fi, liaisons sous-marines ou satellitaires.

A2

Observer le chemin avec tracert

Objectif : mettre en évidence le passage par plusieurs équipements réseau.

  1. Dans l'invite de commandes, saisir tracert education.gouv.fr.
  2. Compter le nombre d'étapes visibles.
  3. Comparer le résultat avec celui d'un camarade.
  4. Proposer une raison pouvant expliquer des différences.
Certains équipements peuvent ne pas répondre aux requêtes de diagnostic : cela ne signifie pas nécessairement que le trajet est interrompu.
A3

Activité débranchée : faire circuler des paquets

Par groupes, attribuer à plusieurs élèves le rôle de routeur. Chaque « paquet » possède une destination. Le but est de faire parvenir tous les paquets au destinataire en respectant uniquement les connexions autorisées entre les routeurs.

Question : que se passe-t-il si une liaison devient indisponible ? Peut-on trouver un autre chemin ?
