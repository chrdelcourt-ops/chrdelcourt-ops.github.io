Thème 2 • Le Web

Comment fonctionne une page Web ?

Le Web repose sur des pages reliées par des hyperliens, identifiées par des URL et échangées entre clients et serveurs grâce au protocole HTTP ou HTTPS.

Cours

1. Internet et Web : deux notions différentes

Internet est l'infrastructure réseau mondiale. Le Web est un service qui fonctionne au-dessus d'Internet et permet notamment de consulter des pages reliées entre elles.

Exemple : un navigateur Web utilise Internet pour communiquer avec un serveur Web.

Cours

2. Hypertexte et hyperliens

Une page Web peut contenir des hyperliens. Ils permettent de passer d'une ressource à une autre : page, image, vidéo, document ou autre site.

HTML <a href="cours.html">Voir le cours</a>

La balise <a> permet de créer un lien hypertexte.

Cours

3. Comprendre une URL

Une URL (Uniform Resource Locator) indique l'emplacement d'une ressource sur le Web.

https://www.exemple.fr/snt/web.html
httpsprotocole
www.exemple.frnom d'hôte / domaine
/snt/web.htmlchemin vers la ressource
HTTPS signifie que les échanges HTTP sont protégés par TLS. Cela ne prouve pas à lui seul qu'un site est honnête ou fiable.

Cours

4. HTML : le contenu et la structure

Le langage HTML décrit la structure et le contenu d'une page : titres, paragraphes, images, liens, listes, tableaux, etc.

Le navigateur interprète le document HTML pour construire l'affichage de la page.

<h1>Mon titre</h1>
<p>Mon premier paragraphe.</p>
<a href="page2.html">Suite</a>

Cours

5. CSS : la présentation

Le langage CSS sert principalement à définir la présentation : taille des textes, espacements, disposition, couleurs et apparence générale.

Idée essentielle : HTML = contenu/structure ; CSS = présentation.
h1 {
  font-size: 2rem;
}

p {
  line-height: 1.6;
}

Cours

7. Les moteurs de recherche

Un moteur de recherche explore et indexe de nombreuses pages, puis classe les résultats en fonction de différents critères. L'ordre obtenu n'est donc pas une preuve de vérité.

1Exploration

Des robots parcourent des pages accessibles.

2Indexation

Les informations utiles sont organisées dans un index.

3Classement

Les résultats sont ordonnés selon la requête et divers critères.

Toujours vérifier l'auteur, la date, la source et recouper une information importante avec d'autres sources fiables.

Cours

8. Navigateur, données et confidentialité

Le navigateur propose des paramètres concernant notamment les cookies, les autorisations accordées aux sites, l'historique, les téléchargements et certaines protections de confidentialité.

Un cookie est une petite donnée qu'un site peut demander au navigateur de conserver. Certains sont utiles au fonctionnement d'un service ; d'autres peuvent participer à la mesure d'audience ou au suivi publicitaire.

Cours

9. Publication, droit d'auteur et licences

Une ressource trouvée sur le Web n'est pas automatiquement libre de réutilisation. Avant de publier une image, un texte ou un autre contenu, il faut vérifier les droits et la licence associés.

Réflexe : citer la source ne suffit pas toujours à obtenir le droit de réutiliser une œuvre.

Travaux pratiques

Créer une première page HTML/CSS

Objectif : distinguer le contenu de sa présentation.

TP1

Créer le fichier HTML

Dans un éditeur de texte, créer un fichier nommé index.html contenant :

<!DOCTYPE html>
<html lang="fr">
<head>
  <meta charset="UTF-8">
  <title>Ma première page</title>
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <h1>Bienvenue sur ma page</h1>
  <p>Je découvre HTML et CSS.</p>
  <a href="https://www.education.gouv.fr">Éducation nationale</a>
</body>
</html>
  1. Enregistrer le fichier.
  2. L'ouvrir dans un navigateur.
  3. Modifier le titre et le paragraphe.
  4. Ajouter une deuxième partie avec un titre <h2>.
TP2

Ajouter le fichier CSS

Dans le même dossier, créer style.css :

body {
  font-family: Arial, sans-serif;
  max-width: 800px;
  margin: auto;
}

h1 {
  text-align: center;
}

p {
  line-height: 1.6;
}
  1. Actualiser la page.
  2. Observer ce qui a changé sans modifier le contenu HTML.
  3. Modifier une propriété CSS et expliquer son effet.
A3

Analyser une URL

À partir d'une URL fournie par le professeur, identifier :

  • le protocole ;
  • le nom de domaine ;
  • le chemin éventuel ;
  • la présence ou non de HTTPS.
A4

Comparer des résultats de recherche

  1. Choisir une même requête pour toute la classe.
  2. Observer les premiers résultats.
  3. Identifier les résultats sponsorisés lorsqu'ils sont signalés.
  4. Comparer auteur, domaine, date et objectif des pages.
  5. Expliquer pourquoi le premier résultat n'est pas forcément « le meilleur ».
