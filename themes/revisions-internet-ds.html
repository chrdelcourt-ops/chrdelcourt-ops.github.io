Révision express

Ce que je dois retenir

01

Internet ≠ Web

Internet est le réseau de réseaux. Le Web est un service qui utilise Internet.

02

Switch

Il relie les équipements d'un même réseau local.

03

Routeur

Il relie des réseaux IP différents et choisit où transmettre les paquets.

04

Adresse IP

Elle identifie une interface sur un réseau. IPv4 = 32 bits ; IPv6 = 128 bits.

05

Paquets

Les données sont découpées en paquets qui peuvent suivre des chemins différents.

06

IP / TCP

IP adresse et achemine. TCP ajoute la fiabilité, la remise en ordre et la retransmission.

07

DNS

Il associe un nom de domaine à une adresse IP.

08

Passerelle

C'est l'adresse du routeur local utilisée pour joindre un autre réseau.

QUESTION RÉDIGÉE 1

Expliquer le trajet P1 → T1

Décris le chemin du paquet en utilisant P1, SW-A, R1, SW-B et T1.

Voir une réponse possible

P1 → SW-A → interface 192.168.1.254 du routeur R1 → interface 192.168.2.254 de R1 → SW-B → T1.

QUESTION RÉDIGÉE 2

Pourquoi TCP ne garantit-il pas une communication rapide ?

Explique la différence entre fiabilité et délai.

Voir une réponse possible

TCP peut retransmettre les données perdues et les remettre dans l'ordre, ce qui améliore la fiabilité. Mais il ne promet pas qu'elles arriveront avant une durée précise.

QUESTION RÉDIGÉE 3

Que fait le navigateur pour ouvrir www.snt-lab.fr ?

Donne les deux grandes étapes observées dans le TP.

Voir une réponse possible

Le poste interroge d'abord le DNS pour obtenir 192.168.2.30. Le navigateur contacte ensuite le serveur Web à cette adresse et demande la page.
